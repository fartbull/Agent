# Pi

## Overview

Pi is an AI assistant from **Inflection AI**. Available at [pi.inflection.ai](https://pi.inflection.ai) on the web, and as mobile apps on iOS and Android.

Pi is primarily a **conversational AI** — it excels at dialogue, brainstorming, learning, and emotional intelligence. It is **not** a coding agent with CLI tool access.

## Key Details

| Detail | Value |
|--------|-------|
| Developer | Inflection AI |
| Platforms | Web, iOS, Android |
| Command | None (web/app only) |
| Config location | None (managed via account settings in app) |
| Open source | No |
