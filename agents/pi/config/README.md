# Pi Configuration

Pi has **no local configuration files**.

All settings are managed through:
- The web interface at [pi.inflection.ai](https://pi.inflection.ai)
- The mobile app settings

## Account Settings (in-app)

| Setting | Options |
|---------|---------|
| Conversation tone | Friendly, Professional, Direct |
| Voice | Various (web only) |
| Notifications | On/Off |

## FARTBULL Integration

Since Pi has no config files, FARTBULL documentation applies as:

- **Prompts:** Use conversational prompts suited to Pi
- **Memory:** Pi maintains conversation history server-side
- **Safety:** Pi's built-in safety handles most concerns; your prompts should still be safe
