# Pi Setup

## Installation

Pi is a web-based and mobile AI assistant. No installation required.

### Access Methods

1. **Web:** Go to [pi.inflection.ai](https://pi.inflection.ai)
2. **iOS:** Download "Pi AI" from the App Store
3. **Android:** Download "Pi" from Google Play

### Account

- Sign up with email, phone number, or X (Twitter) account
- No API key required
- No CLI installation

## Authentication

- Managed through the Inflection account system
- No local auth tokens or config files

## Verification

- Open pi.inflection.ai in a browser
- Send a message — if Pi responds, setup is complete
