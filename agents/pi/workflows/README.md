# Pi Workflows

Pi workflows are **conversational workflows** — you work with Pi through chat, not through autonomous task execution.

## Common Workflows

### Learning

1. Ask Pi to explain a concept
2. Ask follow-up questions
3. Request a summary or key takeaways
4. Ask for resources to learn more

### Brainstorming

1. Describe your project or problem
2. Ask Pi for ideas or approaches
3. Evaluate and refine ideas through discussion
4. Ask Pi to help prioritize

### Writing & Drafting

1. Ask Pi to draft a section
2. Review the draft together
3. Iterate on tone, structure, clarity
4. Use Pi to proofread final text

### Research

1. Ask Pi about a topic
2. Request sources and further reading
3. Use Pi to summarize complex materials
4. Ask Pi to fact-check claims

## What Pi Cannot Do

- Cannot execute code
- Cannot read local files
- Cannot run terminal commands
- Cannot access the internet in real-time
- Cannot be scheduled or automated
