# Pi Prompts

Pi works best with **conversational, natural language** prompts.

Unlike coding agents, Pi does not read config files or respond to slash commands. You interact with it through chat.

## Prompt Patterns

### Research Assistant

```
I'm researching [topic]. Can you explain the key concepts and summarize the current state of the field?
```

### Explanation

```
Explain [technical concept] like I'm a developer who knows programming basics but is new to [field].
```

### Brainstorming

```
I'm building [project type]. Can you brainstorm 5 creative approaches and the tradeoffs of each?
```

### Draft Review

```
Here's a draft of my writeup. Can you review it for clarity, conciseness, and correctness?

[PASTE DRAFT]
```

### Creative Writing

```
Write a short explanation of [concept] using a cooking analogy. Keep it under 300 words.
```

## What Doesn't Work

- Do NOT expect Pi to run code or tools
- Do NOT ask Pi to read local files
- Do NOT expect Pi to execute terminal commands
