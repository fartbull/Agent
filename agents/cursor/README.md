# Cursor

## Overview

**Cursor** is an AI code editor with a built-in agent. It provides an IDE experience with native AI integration: inline editing, agent mode, and a dedicated chat interface.

## Key Details

| Detail | Value |
|--------|-------|
| Developer | Cursor (cursor.sh) |
| Command | `cursor` (CLI) or GUI editor |
| Config location | `.cursor/rules/` (rules) + editor settings |
| Model | Claude (Opus/Sonnet), GPT-4, custom |
| Open source | No |
| MCP Support | Yes |
