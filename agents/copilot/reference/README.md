## Key Features

| Feature | Description |
|---------|-------------|
| **Inline** | AI-assisted autocomplete in editor |
| **Chat** | Conversation-style Q&A |
| **Agent** | Autonomous coding with tool use |
| **CLI** | `gh copilot` for terminal assistance |

## Slash Commands

| Command | Description |
|---------|-------------|

| `/refactor` | Refactor selected code |
| `/fix` | Fix issues in selected code |
| `/document` | Generate documentation |
| `/tests` | Write tests for selected code |
