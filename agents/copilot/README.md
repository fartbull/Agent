# Copilot

## Overview

**GitHub Copilot** is an AI coding assistant from GitHub. It provides autocomplete-style suggestions in editors (VS Code, JetBrains), an agent mode in VS Code, and a CLI tool (`gh copilot`). Copilot uses OpenAI models fine-tuned for coding.

## Key Details

| Detail | Value |
|--------|-------|
| Developer | GitHub |
| Command | `gh copilot` (CLI) or VS Code extension |
| Config location | VS Code settings + `.vscode/settings.json` |
| Model | Custom (GitHub-trained), uses OpenAI behind the scenes |
| Open source | No |
| Auth | GitHub account with Copilot subscription |
