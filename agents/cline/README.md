# Cline

## Overview

**Cline** is an autonomous coding agent that integrates with VS Code. It can read and write files, run shell commands, and use external tools through MCP. Cline supports multiple LLM providers and runs in "Ask" or "Act" mode.

## Key Details

| Detail | Value |
|--------|-------|
| Developer | Cline (cline.cline) |
| Command | VS Code extension (`cline` command) |
| Config location | `.clinerules` (project) or `.cline/settings.json` (TODO: verify) |
| Model | Any (Anthropic, OpenAI, Google, Ollama, etc.) |
| Open source | Yes — [github.com/cline/cline](https://github.com/cline/cline) |
| MCP Support | Yes |
| Approval modes | Ask (default), Act (autonomous) |
