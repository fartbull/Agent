# Roo

## Overview

**Roo** (Roo Code) is an open-source VS Code extension and autonomous coding agent — a community fork of Cline with improved mode system, better rules management, and enhanced safety controls.

## Key Details

| Detail | Value |
|--------|-------|
| Developer | Roo Code community |
| Command | VS Code extension (`Roo` command) |
| Config location | `.roo/rules/*.md` (per-mode) + `.roo/settings.json` |
| Model | Any (Anthropic, OpenAI, Google, Ollama, etc.) |
| Open source | Yes — [github.com/roo-code/roo-code](https://github.com/roo-code/roo-code) |
| MCP Support | Yes |
| Modes | Chat, Code, Debug, Ask |
