# Claude Code

## Overview

**Claude Code** is Anthropic's AI coding assistant that runs as a CLI agent in your terminal. It provides a full development toolkit: file system access, bash, web search, browser, and vision — all through natural language.

## Key Details

| Detail | Value |
|--------|-------|
| Developer | Anthropic |
| Command | `claude` |
| Config location | `CLAUDE.md` (project root) + `~/.claude/` (global) |
| Model | Claude (Opus 4 / Sonnet 4) |
| Open source | No |
| Auth | Anthropic API key or Claude account |
