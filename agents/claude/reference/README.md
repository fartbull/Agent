## Key Features

- `CLAUDE.md` project context (auto-loaded)
- Slash commands (`/agent`, `/model`, `/help`, `/continue`, `/compact`)
- Built-in tools: file edit, bash, web search, browser, grep, glob
- Agentic mode (`/agent`) for autonomous multi-step tasks
- Interactive mode for conversational assistance

## Notes

- Requires Claude account or API key
- `CLAUDE.md` is the primary project configuration file
- Slash commands provide agent control
- `/agent` mode runs autonomously with tool access
