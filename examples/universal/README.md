# Universal Examples

This directory contains universal example workflows and patterns that work across all supported agents.

## Contents

| File | Description |
|------|-------------|
| [coding-patterns.md](coding-patterns.md) | Common coding patterns that work across agents |
| [multi-agent.md](multi-agent.md) | Using multiple agents together |
| [safety-checklist.md](safety-checklist.md) | Safety checklist before running agents |
| [troubleshooting.md](troubleshooting.md) | Troubleshooting common agent issues |

## Relationship to Per-Agent Examples

Each agent folder (e.g., `agents/pi/`) has its own `examples/` directory with agent-specific examples. This directory provides universal patterns that any agent can use.
