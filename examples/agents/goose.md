# Goose Examples

## Example 1: Non-Interactive

```bash
goose -i "Create a Python script that parses a CSV file"
```

## Example 2: Bug Fix

```bash
goose -i "Fix the race condition in src/worker.go. Run: go test ./..."
```

## Example 3: With Config

```bash
goose -i --config ~/.config/goose/config.yaml "task"
```
