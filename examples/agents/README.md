# Agent-Specific Examples

This directory contains brief example workflows for each supported agent.

## Structure

```
examples/agents/
├── README.md          ← This file
├── pi.md              ← Pi examples
├── codex.md           ← Codex examples
├── claude.md          ← Claude Code examples
├── gemini.md          ← Gemini examples
├── opencode.md        ← OpenCode examples
├── cursor.md          ← Cursor examples
├── aider.md           ← Aider examples
├── cline.md           ← Cline examples
├── roo.md             ← Roo examples
├── goose.md           ← Goose examples
├── copilot.md         ← Copilot examples
└── external.md        ← External template
```

Each file contains 2-3 short example prompts demonstrating how to use that specific agent. For full examples, see the agent's own `examples/README.md`.
